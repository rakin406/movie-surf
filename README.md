## Getting Started

To get a local copy up and running follow these simple steps.

### Installation

1. Get TMDB and Jackett API keys.
2. Clone the repo
   ```sh
   git clone https://github.com/rakin406/movie-surf.git
   ```
3. Enter your API keys in `.env`
   ```js
   TMDB_ACCESS_TOKEN="ENTER YOUR TMDB ACCESS TOKEN"
   JACKETT_API_KEY="ENTER YOUR JACKETT API KEY"
   ```
